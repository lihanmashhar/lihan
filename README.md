# Water Intake Tracker

React + Vite app. Log water, set a daily goal, see today's progress, a 7-day history and your streak. Data is saved in localStorage.

```
npm install
npm run dev      # http://localhost:5173/fullstack-task2/
npm run build
```

Deploys to GitHub Pages via `.github/workflows/deploy.yml`
(repo Settings > Pages > Source: GitHub Actions).
